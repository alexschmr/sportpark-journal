# Sportpark Journal online

Die Online-Stadionzeitung des FC Tirschenreuth.

## Aufbau
- `index.html`: die komplette Seite mit Texten, Spielplänen und Code
- `img/`: alle Bilder
- `fonts/` und `fonts.css`: Schriften, lokal gehostet (keine Verbindung zu Google)
- `.nojekyll`: sorgt dafür, dass GitHub Pages die Dateien unverändert ausliefert

## Aktualisieren
Neue Version von Claude herunterladen, alte Dateien im Repository ersetzen, „Commit changes“. Nach ein bis zwei Minuten ist die Seite aktuell.
